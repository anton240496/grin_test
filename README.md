# Telegram Чат на React

Простое приложение для отправки и получения текстовых сообщений через Telegram API с использованием сервиса [GREEN-API](https://green-api.com/Telegram).

## Требования

- Node.js (версия 16 или выше)
- npm (менеджер пакетов)

## Установка и запуск

Выполните следующие шаги для локального запуска проекта:

```bash
# Клонирование репозитория
git clone https://github.com/your-username/telegram-chat-green-api.git

# Переход в директорию проекта
cd telegram-chat-green-api

# Установка зависимостей
npm install

# Запуск приложения в режиме разработки
# сборка  
npm run build
# запуск
npm start
```

Приложение будет доступно по адресу `http://localhost:3000`

## Как получить учетные данные GREEN-API

> ⚠️ **Главное, что нужно понимать:** `idInstance` и `apiTokenInstance` нельзя
> придумать. Это адрес и ключ конкретного инстанса на серверах GREEN-API. Если
> ввести случайные цифры (например, `11223`), сервер ответит ошибкой
> **401 Unauthorized** — и это правильное поведение, а не ошибка приложения.

Порядок получения реальных данных:

1. Зарегистрируйтесь в личном кабинете — [console.green-api.com](https://console.green-api.com).
2. Создайте **инстанс** (экземпляр аккаунта, через который будут идти сообщения).
   Для тестов достаточно бесплатного тарифа **Telegram Developer**.
3. **Авторизуйте инстанс** — без этого шага отправлять сообщения нельзя:
   - в личном кабинете выберите инстанс и нажмите **«Получить QR»**;
   - откройте Telegram на телефоне: **Настройки → Устройства → Подключить устройство**;
   - отсканируйте QR-код.
4. Скопируйте `idInstance` и `apiTokenInstance` из карточки инстанса и введите их
   в форму входа.

### Пример: как выглядят настоящие данные

Значения ниже — **иллюстрация формата**, а не рабочие ключи. Свои нужно взять
в личном кабинете.

| Поле | Пример значения | Пояснение |
| --- | --- | --- |
## к примеру
| `idInstance` | `412345678912` | 12 цифр |
| `apiTokenInstance` |'d123abcd123abcd123abcd123abcd123abcd123abcd12345ab' | длинная строка, около 50 символов |
| `apiUrl` | `https://4100.api.green-api.com` | адрес API из кабинета, необязательно |

> 💡 **Почему `11223` не подойдёт:** номера инстансов выдаёт только кабинет
> GREEN-API, произвольных не существует. Кроме того, сверка идёт по паре
> «номер инстанса + токен», поэтому даже с существующим номером чужой токен
> не сработает — сервер отвечает `401 Unauthorized`.
>
> 🔒 Приложение проверяет формат введённых данных до обращения к серверу:
> `idInstance` должен содержать **ровно 10 цифр**, а токен — быть достаточно
> длинной строкой (около 50 символов). Если ввести `11223`, форма сразу
> подскажет, что формат неверный.

### Про поле «API URL»

Адрес API у GREEN-API **зависит от номера инстанса**: инстансы разведены по
разным хостам, чтобы распределить нагрузку. В официальном SDK для Telegram по
умолчанию используется хост вида `https://4100.api.green-api.com`, где `4100` —
это **первые четыре цифры** `idInstance`.



Проверить, что всё готово, можно в личном кабинете: состояние инстанса должно быть
**`authorized`**. Именно это приложение проверяет при входе — если инстанс ещё не
авторизован или не запущен, форма не пустит дальше и объяснит причину.

### Что означают ошибки

| Что видно на экране | Причина | Что делать |
| --- | --- | --- |
| `Ошибка 401. Неверный apiTokenInstance` | Токен указан неверно или скопирован не полностью | Скопируйте токен из личного кабинета заново |
| `Ошибка 403. Неверный idInstance` | Неверный номер инстанса | Проверьте `idInstance` в личном кабинете |
| `Инстанс не авторизован...` | Данные верны, но QR-код не отсканирован | Авторизуйте инстанс по QR-коду |
| `Инстанс запускается...` | Сервер поднимает инстанс | Подождите около минуты и войдите снова |
| `Этот номер не зарегистрирован в Telegram` | У получателя нет аккаунта Telegram | Проверьте номер телефона |

## Использование

### 1. Вход с использованием учетных данных GREEN-API

1. Перейдите на сайт приложения
2. Введите `ID Instance` и `API Token Instance` из вашего аккаунта GREEN-API
3. Нажмите кнопку "Войти"

### 2. Создание чата

1. После аутентификации введите номер телефона получателя в формате `79991234567`
   (знаки `+`, пробелы и дефисы тоже допустимы — приложение оставит только цифры)
2. Нажмите кнопку **«Создать чат»** — только после этого откроется окно переписки
3. Если номера нет в Telegram, появится сообщение об ошибке

### 3. Отправка сообщений

1. В текстовом поле введите сообщение
2. Нажмите кнопку «Отправить» или нажмите Enter
3. Полученные ответы будут отображаться в окне чата автоматически
4. Кнопка «✕» в шапке чата закрывает переписку и возвращает к выбору получателя

## Функциональность

- Отправка текстовых сообщений через GREEN-API
- Автоматическое получение новых сообщений (опрос сервера каждые 4 секунды)
- Проверка номера получателя сервисным методом `checkAccount`
  (если номера нет в Telegram — приложение честно об этом сообщит)
- Сохранение учетных данных в localStorage
- Интерфейс, похожий на Telegram Web

## Как работает получение сообщений

Приложение использует технологию **HTTP API** (без Webhook), поэтому сообщения
забираются «по одному» в цикле:

1. раз в 4 секунды вызывается метод `receiveNotification`;
2. если очередь пуста, сервер отвечает `null` — ничего не делаем;
3. если пришло уведомление — сразу вызывается `deleteNotification`
   с его `receiptId` (без этого сервер будет отдавать одно и то же
   уведомление повторно);
4. из уведомления берётся текст (`typeMessage === 'textMessage'`) и
   добавляется в чат, если сообщение относится к открытому сейчас диалогу.

## API GREEN-API

Приложение использует методы GREEN-API **для Telegram**:

- [Отправить текст (SendMessage)](https://green-api.com/telegram/docs/api/sending/SendMessage/) — отправка сообщений;
- [Получить уведомление (ReceiveNotification)](https://green-api.com/telegram/docs/api/receiving/technology-http-api/ReceiveNotification/) — получение входящих сообщений;
- [Удалить уведомление (DeleteNotification)](https://green-api.com/telegram/docs/api/receiving/technology-http-api/DeleteNotification/) — подтверждение обработки уведомления;
- [Проверить наличие аккаунта (CheckAccount)](https://green-api.com/telegram/docs/api/service/CheckAccount/) — получение внутреннего `chatId` по номеру телефона;
- [Получить состояние инстанса (GetStateInstance)](https://green-api.com/telegram/docs/api/account/GetStateInstance/) — проверка учетных данных при входе.

> **Важно:** адреса методов сохранили исторический префикс `waInstance`
> (наследие WhatsApp-версии API) — это не ошибка. Метод `deleteNotification`
> вызывается HTTP-методом `DELETE`, а `receiptId` передаётся прямо в URL.

## Особенности реализации

- Приложение использует React 18 с TypeScript
- Состояние компонентов управляется с помощью React Hooks
- Запросы к API выполняются с помощью библиотеки axios
- Чат открывается **только по нажатию кнопки «Создать чат»**, а не во время
  набора номера: для этого введено отдельное состояние `activeChat`
- Сообщения отправляются по внутреннему `chatId` (его даёт `checkAccount`),
  а если метод недоступен — по номеру в формате `79991234567@c.us`
- Защита от дублей: каждое сообщение имеет уникальный `idMessage`,
  повторно в список оно не добавляется
- Опрос сервера автоматически останавливается при закрытии чата или выходе
  из аккаунта (таймер корректно очищается в `useEffect`)
- При входе учетные данные проверяются методом `getStateInstance`: если токен
  неверный или инстанс не авторизован, приложение объяснит причину, не открывая чат
